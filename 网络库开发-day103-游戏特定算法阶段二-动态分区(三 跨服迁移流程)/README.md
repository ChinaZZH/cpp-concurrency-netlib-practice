# Day103： 游戏特定算法阶段二   动态分区(三 跨服迁移)

## 核心收获

-- 1.  完成跨服迁移流程。

-- 1.1.  从跨服迁移的源结点分区开始，先锁定，然后获取该分区的对应数据。

-- 1.2.  将获取到的数据传输到目标节点。

-- 1.3.  在目标节点进行数据的重放和处理，返回处理结果给源节点的分区。

-- 1.4. 源节点收到目标节点的处理结果，则在源节点上移除该分区。

-- 1.5. 若源节点的所有分区都被移除，则该工作节点可以下线。 这个就是实现动态扩容缩容的过程。

-- 2.  整个过程涉及状态机变化和数据传输。
