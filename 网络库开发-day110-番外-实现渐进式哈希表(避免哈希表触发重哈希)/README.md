# Day110： 番外  实现渐进式哈希表

## 核心收获

-- 1.    了解 stl 中的哈希表 hashTable 触发重哈希的条件是   负载因子>=所设定的负载阈值。  

-- 2.    负载因子 可以通过 元素个数/哈希的桶的个数 计算求得。 即  map.size() / map.bucket_count() 。

-- 3.   负载因子的阈值可以通过 max_load_factor(load_threshold_) 来设置， 也可以通过 max_load_factor() 来获取。

-- 4.   插入元素的时候当处于 迁移状态中的 时候，就往备用哈希表中插入。 

-- 5.   如果不处于迁移状态中，在插入数据前先判断插入数据是否会发生重哈希，如果不会发生则正常往主表插入， 如果会发生则进行迁移状态的设定和初始化。

-- 6. 当处于迁移状态中的时候，每次插入和删除， 都需要把主表往备用表迁移两三个元素。当元素全部迁移完成后，交换主表和备用表的内容，同时重置迁移状态。
