# Day109： 游戏特定算法阶段二   RVO群体避障

## 核心收获

-- 1.   核心是 Update函数，每帧运行。

-- 2.   在一帧里面，agent列表的每一个agent都先后来进行移动，按照时间顺序来进行速度和方向的判定然后进行移动。

-- 3.   判定前，先判定是否已经达到目标位置。如果还没有达到以当前点目标点的直线运行为最佳方向和当前速度为最佳速度。

-- 4.   在真正移动前，先根据角度和速度来选取候选速度。

-- 5. 在真正移动前，需要在避障目标下的最佳方向和速度。 先过滤会发生碰撞的情况，如果没剩下符合条件的，则原地不动。

-- 6. 如果在 5 后还有符合条件的，则选取最接近 3 最佳方向速度。
