# Day93： 集成游戏特定算法  数据一致性(事件溯源)

## 核心收获

-- 1.  增加事件日志系统，当玩家主动和系统交互的时候，通过日志系统记录交互信息和数据。
 
-- 2.  在事件日志系统之上增加缓存系统，当写入主动交互信息数据的时候先将数据缓存再写入日志文件。
 
-- 3.  缓存系统设置最大缓存条数，可以自由设置，默认5000条。超过则淘汰最早的缓存信息。

-- 4.  缓存系统通过互斥锁保证线程安全。

-- 5.  缓存系统设置根据玩家id 和 服务端帧号 进行索引。

-- 6.  缓存系统 中的 服务端帧号 可以进行范围查询。
