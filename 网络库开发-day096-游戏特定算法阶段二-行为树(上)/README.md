-- 2.  SequenceNode  顺序节点：依次执行所有子节点，全部成功才算成功

-- 3.  ParallelNode 并行结点。  

-- 3.1.  所有子节点都会被执行（每一帧都会更新）。

-- 3.2.  先检查 all_mask：这些子节点必须全部成功（任一失败 → 整体失败）
 
-- 3.3.  再检查 any_mask：这些子节点任意一个成功 → 整体成功。如果any_mask 没有掩码(为0) 则直接返回成功。

-- 3.4.  否则返回 Failure
