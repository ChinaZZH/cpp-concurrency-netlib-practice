# Day108： 游戏特定算法阶段二   NavMesh网格导航

## 核心收获

-- 1.   根据网格的连通性划分成不同的区域。(使用并查集的方法将同一个区域的网格合并，同时用以下方法来处理连通区域的判断)。
```text
基于连通性的区域标记（原始算法）
	1. 遍历所有格子，只处理可行走格子

     2. 检查当前格子的上方和左方邻居：

         2.1. 如果上方和左方都不可行走 → 新区域

         2.2. 如果只有上方可行走 → 继承上方的区域 ID

         2.3. 如果只有左方可行走 → 继承左方的区域 ID

         2.4. 如果上方和左方都可行走但区域 ID 不同 → 合并两个区域

    3. 第二次遍历，统一区域 ID（路径压缩）
```

-- 2.   将不同的连通区域提取为不同的多边形。

-- 3.   提取多边形的时候先收集这个区域的边界格子，然后根据所有的边界点计算出中心点，再然后将边界点按照离中心点的tan角度的高低排序，取出相同的边界点，重新计算中心点。

-- 4.   完成步骤3之后 利用叉积 取出公共的点，只算边的两边的点。 

-- 4.1 也就是如果前后三个点(pre, current, next), pre点current点两点组成的线 和 current点next点两点组成的线 两条线斜率相同也就是同一条线的话，那么就过滤current点。然后重新计算中心点。

-- 5. 判断一个点是否在多边形内，可以通过射线法来进行计算判断。
